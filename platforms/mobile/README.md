# Móvil: siguiente entrega

La versión Android se habilita después de aprobar la beta web. Capacitor
envolverá la misma aplicación React + Phaser, con una variante de interfaz
vertical de 90 segundos, teclado táctil, hápticos y controles grandes.

Las compras y anuncios recompensados no existen en la web actual. Solo se
integrarán aquí con productos verificados de Google Play y sin ventajas de
jugabilidad para quien pague.

Keyboard test no forma parte del alcance móvil inicial: es una herramienta
gratuita exclusiva de la web, pensada para probar teclados físicos ANSI e ISO.

## Preparación ya aplicada

- El motor recibe duración de partida por configuración; el viewport móvil usa
  90 segundos y el escritorio 180.
- La interfaz tiene teclado táctil, botones de poder y reglas responsive.
- El contenido, temporadas y cosméticos usan contratos independientes de la
  plataforma.
